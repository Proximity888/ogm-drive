1. ข้อมูลที่โปรแกรมเข้าถึง / Data the app accesses

MIDI-OGM เข้าถึงเฉพาะไฟล์ในโฟลเดอร์ที่กำหนดไว้ใน Google Drive ของบัญชีที่องค์กรเป็นเจ้าของ เพื่อดาวน์โหลดไฟล์เพลง (สิทธิ์อ่านอย่างเดียว) และให้ผู้ดูแลระบบอัปโหลด/จัดการไฟล์เพลง (สิทธิ์ Google Drive)

MIDI-OGM only accesses files in a designated folder of a Google Drive account owned by the organization, in order to download song files (read-only access) and to let administrators upload and manage song files (Google Drive access).

2. การใช้และจัดเก็บข้อมูล / How data is used and stored

  • ไฟล์เพลงที่ดาวน์โหลดจะถูกเก็บไว้ในเครื่องคอมพิวเตอร์ของผู้ใช้เท่านั้น / Downloaded song files are stored only on the user's computer.
  • ข้อมูลสิทธิ์การเข้าใช้ (token) เก็บไว้ในเครื่องคอมพิวเตอร์ที่ติดตั้งโปรแกรม / Access credentials (tokens) are stored locally on the computer where the app is installed.
  • โปรแกรมไม่มีเซิร์ฟเวอร์ของตัวเอง ไม่เก็บข้อมูลส่วนบุคคล ไม่มีการติดตามการใช้งาน และไม่ส่งต่อข้อมูลให้บุคคลภายนอก / The app has no server of its own, does not collect personal information, does not track usage, and does not share data with third parties.
  • ข้อมูลจาก Google ใช้เพื่อให้บริการดาวน์โหลด/อัปโหลดไฟล์เพลงภายในองค์กรเท่านั้น / Google user data is used only to provide song file download/upload within the organization.

3. การปฏิบัติตามนโยบายของ Google / Google API Services User Data Policy

MIDI-OGM's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. การยกเลิกสิทธิ์ / Revoking access

เจ้าของบัญชีสามารถยกเลิกสิทธิ์ของโปรแกรมได้ทุกเมื่อที่ https://myaccount.google.com/permissions

The account owner can revoke the app's access at any time at the link above.
