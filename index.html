MIDI-OGM (OGM Drive)

โปรแกรมบน Windows (Windows 7 – Windows 11) สำหรับใช้ภายในองค์กร เพื่อแจกจ่ายและอัปเดตไฟล์เพลงคาราโอเกะระหว่างเครื่องคอมพิวเตอร์ขององค์กร โดยเก็บไฟล์ไว้ใน Google Drive ของบัญชีที่องค์กรเป็นเจ้าของ

A Windows desktop application (Windows 7 – 11) used internally by our organization to distribute and update karaoke song files between the organization's computers. Files are stored in a Google Drive account owned by the organization.

ความสามารถ / Features

  • ค้นหาและดาวน์โหลดเพลงจากคลังเพลงขององค์กร / Search and download songs from the organization's library
  • ดาวน์โหลดเพลงใหม่อัตโนมัติ / Automatically download new songs
  • ผู้ดูแลระบบนำเข้าและอัปโหลดชุดเพลงใหม่ / Administrators import and upload new song packs
